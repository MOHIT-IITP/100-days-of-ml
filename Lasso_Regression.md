# LASSO REGRESSION

- reduces overfitting

- [ L = MSE - λ|w| ]

"λ is alpha in the code"

- [!important] if λ = 0 then the "lasso regression" -> "Linear regression"

[!IMPORTANT]

> if λ increases then it will use feature selection , extra (unnecessary cols will become zero
> and you can choose the best fit cols).

[!tip]

> If you increase the alpha too much then the all cols of data will become zero.

- [!IMPORTANT] if λ increase then overfitting decreases , variance decreases , Bias increases

{ Total error => Sum of Bias + Variance }
